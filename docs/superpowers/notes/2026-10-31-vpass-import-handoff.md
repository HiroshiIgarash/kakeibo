# 引き継ぎ: 通知メールが届かない明細の取り込み（Vpass 直接取得）

作成: 2026-10-31（クラウドセッションから Mac ローカルへの引き継ぎ用）

## ゴール
三井住友カードの「ご利用のお知らせ」メールが届かない明細（主に継続課金）を、
CSV アップロード・手入力・固定値設定 **以外** の方法で自動反映する。

## 調査で確定したこと

### 1. 通知メールが来ないのは「継続課金」だけ
- 9/8〜10/28 の Vpass 明細 133 件と Gmail の通知メールを突き合わせた結果、未通知は 15 件のみ。
- 通常の買い物（ベルク・セブン・コンビニ・交通タッチ決済等）は全件通知されていた。
- 通知メール本文に明記あり:
  「※携帯電話や公共料金などの継続的なご利用 及び ETCやPiTaPa等、一部の電子マネー利用については通知されません。」
- Vpass「ご利用通知サービス」設定: 通知する / 11円以上 / メール + Vpassアプリプッシュ（問題なし）。

### 2. 使えない／見送った手段
- 「お支払い金額のお知らせ」メール: 本文に金額も明細も無い（Vpass 設定で合計額表示は可能らしい）。
- 「ご利用明細のお知らせ」（確定時通知）: 2か月で Amazon 返品 1 件のみ。継続課金は載らない。
- マネーフォワード ME: 個人向け API なし。アラートメールは金額・日付のみで店名なし。
- Moneytree: 個人向け API なし（LINK API は法人向け）。メールは請求額確定の合計のみ。
- 請求元メールを送信元別パーサーで取り込む案（案A）: ユーザー判断で見送り。

### 3. Vpass ログイン
- 通常ブラウザ・シークレットウィンドウとも、ID/パスワード以外の追加認証は求められなかった。
- ただし海外 IP（GitHub Actions 等）からのアクセスで追加認証・ブロックされるかは未検証。

## 採用方針: 案E2（Vpass Web の内部通信を直接呼ぶ）
- ブラウザ操作ではなく、Vpass Web 画面が裏で使う HTTP API を直接叩いて明細を取得する。
- 非公開 API のため予告なく変わり得る。壊れたら E1（Playwright によるブラウザ自動操作）へ切り替える前提。
- 取り込み時は通知メール由来の取引と **金額一致 + 日付 ±2日** で突合し、未登録分のみ insert する
  （店名は表記が異なる: 例 `BELC WAKOSHIRAKO` ↔ `ベルク 和光白子店`）。
  この突合ルールを 9〜10月の実データに当てると、残るのは継続課金 15 件のみで誤検出なし。

## 次のアクション
1. **内部 API の調査**（Mac の Chrome / Claude in Chrome で）
   - Vpass にログイン後（ログイン操作は記録しない＝パスワードを含めない）、明細ページを開き、
     ネットワーク通信を記録する。
   - 調べること: 明細データを返す URL とレスポンス形式（JSON/HTML）、確定分・未確定分（現在判明分）の
     取り方、お支払い月の指定方法、認証の保持方法（Cookie / トークン）。
   - 手がかり: 「お支払い金額のお知らせ」メール内のリンク `https://www.smbc-card.com/memapi/jaxrs/meisai/v1`、
     明細印刷ページ `https://www.smbc-card.com/memx/web_meisai/top/index_prt.html?p01=YYYYMM&p03=1`。
2. 明細取得が分かったら、ログインフローを別途調査。
3. 実行場所の決定（GitHub Actions を第一候補、海外 IP で弾かれたら日本の VPS かローカル Mac）。
4. 設計書・実装計画（TDD）を `docs/superpowers/specs|plans/` に作成して実装へ。

## 未解決・宿題
- **Vpass 会員規約の確認**（https://www.smbc-card.com/mem/kiyaku/pop/kiyaku_vpass.jsp ）:
  自動化アクセス禁止条項の有無。E2 は規約上いちばんグレーなので先に確認する。
- Vpass ID/パスワードを Secrets に置くリスク（Vpass ではリボ変更等も可能）の受容判断。
- 未確認の請求元メール（UQ / Google / ニコニコ / Amazon / Cloudflare）は E2 採用により優先度低。

## 調査上の注意（再発防止）
- Gmail は同件名の通知メールを 1 スレッドにまとめる。`search_threads` の `messageCount` は
  実際の通数と一致しないことがあるため、必ず `get_thread` で全メッセージを読むこと。
- Vpass の明細 PDF は日本語 CMap 依存。`pdftotext` は `poppler-data` が無いと文字化けする。
